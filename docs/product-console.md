# 星云知识控制台（产品规格 · MVP）

> 分支：`product/knowledge-console`  
> 定位：把已跑通的 RAG **变成可运营的内部知识助手**，不是另做一套检索引擎。

## 1. 为什么现在做

12 周主线已经能答、能路由、能拒答。还缺的是运营闭环：

- 语料仍靠往 `data/corpus/` 丢文件再跑 CLI
- 切片好坏只能靠问答反推（`production-gap` P1-7）
- 现有 Gradio 只覆盖「员工提问」

**产品判断**：先做控制台，再谈 CLIP / Ragas / 公网多租户。上传与切片预览会暴露真实解析/切块问题，比再堆检索招式更有学习与演示价值。

## 2. 不是什么

| 不做 | 原因 |
|------|------|
| 多租户 / SSO / 权限矩阵 | 练习项目；公网 SaaS 在计划里明确后置 |
| 动态新建知识库与自定义 Profile | 检索策略必须跟已有 5 库绑定，避免「一个大库吃所有格式」 |
| Word / PPT / 扫描件 OCR | 解析链路未就绪；乱接会污染索引 |
| 回答时回灌原图、CLIP 双塔 | 第 12 周已标明后置 |
| 用 Celery 上生产队列 | 单机后台任务足够；P2-8 等真有并发上传再上 |

## 3. 谁用 · 干什么

| 角色 | 核心任务 | 成功标准 |
|------|----------|----------|
| **知识运营**（HR/IT/行政） | 把制度/手册/表格/图放进对的库，并确认切片合理 | 上传后能看到切块；坏文件能删掉重来 |
| **员工** | 用自然语言问内部问题 | 答案带来源；低置信度拒答 |

MVP 不做登录，同一界面两个工作区切换即可。

## 4. 信息架构

```
问答          面向员工：多轮 ReAct，侧栏展示工具 / 片段 / 引用
知识库        面向运营：选库 → 文档列表 → 上传 → 入库前预览切片 → 确认写入
切片浏览      面向运营：按库/文件查看已入库 chunk（Dify 式 inspect）
```

## 5. 知识库与允许格式（用户选库，禁止静默改路由）

| 库 | 工具 | 允许上传 | 落盘位置 |
|----|------|----------|----------|
| 制度与流程 `policies` | `search_policies` | `.md` `.html` | `data/corpus/internal/{markdown,html}/` |
| 表格 `tabular` | `search_tabular` | `.csv` | `data/corpus/internal/csv/` |
| PDF 手册 `pdf` | `search_pdf_handbook` | `.pdf` | `data/corpus/kb_pdf/pdf/` |
| 图文 `multimodal` | `search_visual` | `.png` `.jpg` `.jpeg` `.webp` | `data/corpus/kb_multimodal/images/` |
| 关系图谱 `relations` | `query_relations` | `.md` | `data/corpus/kb_graph/markdown/` → `ingest-graph` |

错格式直接拒绝并说明该去哪个库。切块/检索策略一律用该库 **已有 Profile**，不按扩展名偷偷换库。

## 6. 关键流程：入库前预览

```
选库 + 选文件
    → 解析 + 按该库 Profile 切块（不写向量）
    → 运营浏览每个切片（字数、正文）
    → 确认入库（向量库 upsert；图谱走 Neo4j 增量）
    → 任务状态：排队 / 进行中 / 完成 / 失败
```

**原则**：上传只 upsert 这批文档，**不得**把库里其它文档当缺失删掉。

## 7. 验收（MVP）

- 往 `policies` 上传一篇 MD：预览能看到按标题切开的块；确认后问答能引用该文件
- 往 `pdf` 上传 PDF：预览为固定窗口块；错传到 `policies` 被拒绝
- 切片页能按库列出已入库 chunk，点开一篇能看全文切片
- 问答与 CLI `--react` 同一条路径
- 单测覆盖：upsert 不误删、格式校验、预览切块

## 8. 技术边界

- API：FastAPI（`python -m rag_assistant.api`，同时托管控制台页面）
- 前端：单页控制台（问答 / 知识库 / 切片），与 API 同进程
- 入库任务：进程内后台线程 + 任务查询；单机足够
- Gradio 保留，不作为控制台主入口
